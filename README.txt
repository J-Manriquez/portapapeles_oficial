MultiClipboard Manager
Descripción
MultiClipboard Manager es una aplicación de escritorio avanzada para Windows que
permite gestionar múltiples elementos del portapapeles de forma eficiente.
Desarrollada en Python con Tkinter, ofrece una interfaz moderna y fácil de usar
con temas claro/oscuro y navegación completa por teclado.

Características Principales
Gestión del Portapapeles
Monitoreo automático del portapapeles en tiempo real
Almacenamiento de múltiples elementos de texto
Soporte para formateo de texto (RTF y HTML)
Límite configurable de elementos almacenados
Opción para pegar con o sin formato
Sistema de Grupos
Creación y gestión de grupos personalizados
Organización de elementos en grupos
Edición y eliminación de grupos
Vista detallada del contenido de cada grupo
Navegación
Navegación completa por teclado
Atajos personalizables
Sistema de resaltado visual para la navegación
Soporte para scroll y mousewheel
Interfaz de Usuario
Temas claro y oscuro
Diseño moderno y minimalista

Tarjetas con previsualización de contenido
